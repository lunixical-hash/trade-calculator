# AFK coin path

Client only. Press Play, set the Studio command bar to **Client**, paste `auto-collect/AutoCollect.lua`.

It finds anything named `CoinVisual` in Workspace, builds a path around walls, and walks with normal character movement. Default controls are turned off while it runs so they do not cancel the walk. A green line shows the route. Only you can see that line. Your server still collects the coins.
